# LaunchDeck

LaunchDeck 是一款面向 macOS 的启动台应用。

## 下载

当前版本：**1.9.30**（通用架构：Apple silicon arm64 + Intel x86_64）

- [下载 LaunchDeck 1.9.30](https://github.com/shutiaostars/LaunchDeck-downloads/releases/tag/v1.9.30)
- 系统要求：macOS 13 或更高版本

## 安装

1. 下载 Release 中的 `LaunchDeck-1.9.30.dmg`。
2. 打开 DMG，将 `LaunchDeck.app` 拖入“应用程序”文件夹。
3. 从“应用程序”启动 LaunchDeck。

如果 macOS 首次启动时显示安全提示，请在“系统设置 → 隐私与安全性”中按系统提示允许打开。
